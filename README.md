## 🔬 主要研究

**🎬 基于 Wan2.1-VACE 的参考图引导视频风格迁移**
在 DiT 每层 Transformer Block 后注入 Cross-Attention 模块，将参考图 CLIP 特征显式引导去噪过程。在多风格视频数据集上 **CLIP-Style 0.498，超越 StyleMaster / TeleStyle / TokenFlow 等全部基线**。

**🧠 信息动力学驱动的生理时序增量学习**
改进 ReduNet 算法从类别增量适配到域增量场景，重新定义展开项 E 与压缩项 C，通过白盒模型逐层展示迭代过程。在 ECG 多域增量任务上 **平均 AUC、平均准确率、BWT 三项指标均为最优**。
